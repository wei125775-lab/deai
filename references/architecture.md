# 架构层（链路第 1 步 · 仅虚构 · 重构/新写档）

来源：sepia `narrative-pass` 七组诊断，按中文网文转译。证据基础是**英文文学语料 + HC3 中文问答**，对网文只取"方向"，数值见 calibration 0.8（待复算）。核心哲学：**对准网文的人类带，不是把 AI 特征反转；每篇只挑 2-5 个动作做；留一处破绽。**

只有**重构档**动刀。清理档遇到本层症状：在报告标出，不动。下面每组给「症状 → 真人做法 → 动作」，动作都要挑着做，别做全套。

## 架构表：动笔前填 / 重构前诊断

| 维度 | 选项 | 网文人类带 |
|---|---|---|
| 因果结算 | 全闭环 / 留一线头 | 大事必结算；小事可留 1-2 处不收回的线头 |
| 收尾模式 | 事件结果 / 内心接受 | 卷尾靠事件结果；内心接受至多当点缀 |
| 意外成本 | 无代价 / 赢也脱层皮 | 大爽点前付一次计划外代价【推断】 |
| 情绪渲染 | 生理为主 / 行为为主 / 直说 | 行为+直说打底，生理留给 1-2 个峰值 |
| 信息节奏 | 前置说明 / 边动边漏 | 边动边漏，前史后置 |
| 配角网络 | 全正向 / 有私利与恶感 | ≥1 条与主角无关的配角利益，≥1 段不和解的恶感 |
| 反派结构 | 孤立敌对点 / 有自己的网 | 反派 ≥1 个不经过主角的关系 |
| 真实参照 | 真空 / 有具体物名 | ≥1 处具体到名字的参照（虚构世界内也算） |
| 稀缺动作 | 无 / 一个 | 每 10-20 章一个"这类书不这么写"的结构选择 |

## 七组诊断（按症状挑，别全做）

### 1 点题癖【A 级，跨语料稳定】
- 症状：爽点落地，角色立刻替作者升华——「他忽然懂了，强者不是不流泪……」；章末总结人生；遇事顿悟、顿悟必成文。sepia：AI 明说主题 77% vs 人类 52%。
- 真人：用事件结算，不上价值；判断留给读者。
- 动作：删叙述层「忽然明白/他终于知道/原来成长就是」类，换成下一个动作；符号被解释过就删解释留符号。**判据是频率**：偶尔章末感慨是真人风格，每次都点题才是病。

### 2 机械化因果（回声测试）【A 级，最实用】
- 症状：冲突恰好解决、代价恰好可控、巧合恰好够用、求助恰好有人；转折可预期，换世界观能重演。
- 真人：爽文要强因果（行业规范，别动），但会留意外成本——赢也脱层皮、有角色没赶上、闲话二十章后成把柄。
- 动作——**回声测试**：对每个转折问"这情节重生成二十次是否每次这么转"。恰好赶到的援军、恰好听懂的规矩、按时的旧敌都会重演；换成只属于本故事、需要付代价的转折。

### 3 收尾三脚架【A 级】
- 症状：高潮后不靠事件收束，靠"主角想通了"——内心戏三页然后豁然开朗、与过去和解；每卷每段都这么结。sepia：AI 内心接受式结局 47% vs 人类 27%。
- 真人：卷尾靠事件结果（境界突破、仇人授首、新威胁入场）。
- 动作：卷尾若踩"决定+接受+成长"三脚架，拆一条腿；删把每笔账算平的收尾；**停在比圆满早一拍的地方**。开放/部分结算在长连载是常态不是缺陷。

### 4 前置说明癖【A 级】
- 症状：开局几百字交代世界观/恩怨前史，一切就绪故事才动（"简报式"开场）。
- 真人：信息边动边漏，开头就是一个正在发生的事件。
- 动作：说明书式开局砍成能动的两三句引子；前史拆进动作间隙；**先给果，原因随冲突漏**。

### 5 情绪只走身体渲染【A 级方向，B 级数值】
- 症状：怕=心跳漏一拍/喉头发紧/指尖发凉连番上阵；生理渲染密度高。
- 真人：心理戏多，但大量直给心理判断+行为（「她怕了，怕到不敢看他」）。注意协调：**sepia 说人类会直接点名情绪，oh-story 说"很紧张"要改"手在抖"**——两者不冲突，统一口径见 gates.md C 门禁：抓的是"抽象情绪壳"（感到一丝/心中涌起一股），直接人话和具体外化都行，别只留生理渲染一种。
- 动作：盘点情绪拍，多数转行为或直说；生理渲染留给 1-2 个峰值；景随情变的情绪化环境呼应连场出现就删到偶尔。

### 6 角色网全正向【A 级】
- 症状：配角都对主角有好感或最终折服；关系净情绪为正；反派孤立成对着主角的敌对点。
- 真人：配角允许工具人（行业常态），但会有与主线无关的私利、互看不顺眼的配角、有自己圈子的反派。
- 动作：画关系网（带正负）。每条边都暖就冷几条——留一个**到尾都不和解**的。反派给一个不经过主角的关系。

### 7 真空感【B 级，受审核规约影响】
- 症状：故事无具体地名/器物/书名人名；"某本古籍""某个大人物"含糊带过；通篇太文气。
- 真人：敢写具体名字、真实器物；有时对读者搭话（网文弹幕感是活人味）。
- 注意：晋江/番茄审核会滤真实参照，那种干净不算 AI 味。
- 动作：一处"某个大人物/古老传承"写成具体可感的名字（虚构内具体也算）；场合允许时破一次第四面墙。

## 稀缺动作（可选，别堆）
每 10-20 章挑一个"这类书不这么写"的结构决定——换叙述距离、用本题材少用的收尾方式、给反派一次不为难主角的戏。**一个**就够，多了是表演。

## 执行纪律
- 诊断先出报告（标症状+拟动作+哪些是减法/哪些需新增剧情授权），**授权后再动刀**。
- 每次只挑 2-5 个动作。做完重跑变动的组即可，不整表复查。
- 加了转折/伏笔，跑一次回声测试确认不是又一次"可预期"。
