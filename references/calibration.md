# 校准与预检（链路第 0 步 + 全链路裁量依据）

## 0.1 判定矩阵：文体 × 档位决定走多深

| 文体 \ 档位 | 清理 | 重构 | 新写 | 检测 |
|---|---|---|---|---|
| 虚构/网文 | 步 2+3+4+5；结构症状只标注提醒 | 全链路含步 1 手术 | 步 1 先填架构再写，写完过 2-5 | 只跑检测 |
| 非虚构文章 | 0 预检加强 + 2+3+4+5（材料稀薄问题先报） | 0 + 重组段落论点（罕见，先问） | 0 材料门槛先过 + 正向写法接 human-writing | 只跑检测 |
| 标题 | 走 `titles.md`，不碰正文 | 同左 | 同左 | 同左 |

## 0.2 现实稿：材料门槛（human-writing 浓缩，非虚构必查）

非虚构要写到一定篇幅，先确认站得住，动笔/改稿前内部过一遍，不过就停：

- 每件重要事实、数字、原话、引语，能说清来自哪（用户哪句话 / 哪份可查来源）。**说不出来路的，不能托住事实段。**
- 想写到约千字以上，至少凑出约 5 件**具体材料**且能串成一条实际过程；凑不出就先别写长稿——先研究、追问（一次最多三个问题），或缩短。绝不用重复解释、扩写观点灌字数。
- 用户经历缺关键处：最多问三句；用户不让问且研究后仍不足，就交更短更实的稿，**别把编的经历安到用户身上**。

虚构稿不查现实出处，改查：每段有没有人物目标/动作/发现/关系变化托住。只换景色和说法、没有事发生，就是注水（human-writing 同规）。

## 0.3 说话位置（human-writing 浓缩，非虚构定向写法用）

动笔前内部回答五件事，答案不交给用户：谁在说、凭什么知道、现在为什么想说、手里什么能托住、他对哪点有明确判断且依据到哪为止。

## 0.4 信息守恒与最小改动（lieflat 硬边界，全链路）

- 白名单式：只处理规则里明确列出的；没命中的句子逐字保留。
- 一处命中，只改解决该问题必需的部分；不顺便润色、不调语气详略。
- 改后每个实词要能在原文指出处，指不出就是新增，撤销。**不许新增**：姓名/机构/数字/日期/引语/来源/因果/动机/心理活动/任何原文没有的细节。**不许删减**：观点、结论、限定词、让步。
- 判断把握不住是否命中时，保持原文。

## 0.5 网文别误伤（C 级禁动，比 A 级还高）

这些是**网文行业规范或真人作者真习惯**，看着像 AI 味但不是，一律不碰：

| 禁动的 | 为什么 |
|---|---|
| 强因果、伏笔全回收、爽点按期结算 | 网文读者的追读契约，真人作者也这么写 |
| 主角主动、高在场 | 被动主角是网文毒点 |
| 短段、段落密集、每段一两句 | 网文读者接受带，真人大量用 |
| 角色多、串场频繁、工具人配角 | 出场密度是行业常态；要砍的是"关系全正向"，不是"全认识" |
| 线性推进 | 长连载基本必须线性 |
| 主角心理独白多 | 网文强项，不是病；病在"独白只有抽象情绪壳"（见 gates C 门禁） |

判断口诀：**网文砍"机械感"（可预期的圆满、模板化的工整），不砍"高密度、强因果、快节奏"。**

## 0.6 反误伤总表（lieflat"不作为改写理由"，C 级）

| 看着像 AI 味 | 实测/结论 | 处理 |
|---|---|---|
| 句长、段落长度不够参差 | 与人类无显著差别 | 不为此调句长拆段 |
| 被动句（抽象被动） | 现代汉语书面语正常写法 | 保留 |
| 名词化、长句本身 | 正常中文写作，人类同样用 | 保留（抓的是"名词化动词壳"那几类，见 gates） |
| 正文"首先……其次……" | 与人类无差别 | 保留（只清小标题"一、二、三"编号，见 gates） |
| 句内同构排比（"更高效、更专注"） | 人类用得不比 AI 少 | 保留。抓的是相邻句同骨架连复现、顿号三连、跨段排比抬价 |
| 问句、设问、问句小标题 | 人类正文问句多于 AI | 保留，删了更不像人 |
| 比喻本身、比喻独立成段 | 人类用得比 AI 多 | 保留；只处理"理想化职业喻体"、功能判断见 gates |
| 重复写全称少用代词 | 人类比 AI 更常重复名词 | 保留 |
| "抽象名词配具体动词"抒情 | 几乎两边都不写，不算信号 | 不作为单独抓点；真出现且肉麻再删 |

## 0.7 模型浮动（sepia model-fingerprint 思路，中文网文版）

同一特征在不同后端模型上量级差很多。**先确认当前执行模型，再定 B/C 级词的力度**。本机后端走 DeepSeek 系（见全局记忆 reference-model-proxy），默认值按 DeepSeek 系标，换模型时按此表调整：

| 特征 | DeepSeek/Claude 系 | Gemini/GPT 系 |
|---|---|---|
| 破折号揭晓 | **A 级**，几乎必清（DeepSeek 实测 5.16/千字 vs 人类 0.80，5 倍+） | 落到 B（它们反而低于人类，清它=造反指纹） |
| 省略号停顿 `……` | 网文正文 A 级清（oh-story 全禁） | 同左（网文语境稳定，与模型无关） |
| 顿号三连罗列 | A | A（人类 1.78 vs AI 3.21，稳定） |

拿不准当前模型时按上表 DeepSeek 档执行并在报告注明。

## 0.8 网文"人类带"待复算清单（诚实标注，别当常数）

下面这些目前是**单源推断或英文文学/问答语料结论**，对中文网文的人类带还没用自有语料标定。建议拿你自己的中文语料跑句式统计（句长分布、顿号密度、情绪表达模式占比）复算，算完把数值填回来；复算前一直按"方向对、数值待定"处理：

- 情绪渲染模式占比：生理渲染 vs 直接点名 vs 行为外化（sepia 英文数据：身体渲染 AI 81% vs 人类 38%；直说人类 29% vs AI 8%——**方向**在网文也成立，占比待网文语料复算）
- 章末点题/升华频率（真人作者偶尔章末感慨是风格，判据是频率）
- 语气词、叠字、单字动词密度
- 对话标签密度（"说道/问道/笑道"占比；oh-story 给了阈值 ≤30-50%，来自其网文采样，可复核）

数据回来前，遇到这些维度只做**相对判断**（"这段比全文其余部分明显更模板"），不做绝对值指控。
