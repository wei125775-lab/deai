# 句级门禁（链路第 3 步）

三家句级规则合一：lieflat（11 条触发标记）、human-writing（表演性中文句层）、oh-story（门禁 A-G 网文版）。每条带 **级**（A 必改 / B 标出问 / C 禁动）、**源**（LF=lieflat、HW=human-writing、OS=oh-story、SE=sepia）。命中 A 级做最小改动；B 级列出来让用户定；C 级碰都不要碰。

> 命中但"作者本来就这么写"（风格文档/原稿习惯）→ C 级覆盖一切，不碰。

## G-A 翻案腔动作【A｜LF+HW+OS，三方同判】
先立一个读者并没有的误解再推翻它。**按动作查，不按字面查**——穿任何字面都是它：

字面：不是A而是B／并非A而是B／不在于A而在于B／与其说A不如说B／表面A实际B／看似A实则B
省字：不是A，是B／不是A。而是B
以为体：你以为A，其实B／我一直以为A，后来才发现B／回头才发现
让转体：大家都说A，可真相是B／答案恰恰相反
抬价体：A不重要，重要的是B／真正值钱的从来都与A无关
变形例（OS 网文版）："他不是冷漠，而是绝望"／跨段"不是A。/也不是B。/只是C。"

改法：找到它想下的那个判断，从正面直接说，依据放旁边。只有文章真用材料走过从误解到修正的过程，才允许一次自我修正，但不能穿上面任何一件外衣。

## G-B 万能状语与声音模板【A｜LF+OS】
- "，带着……"万能状语："他笑了一下，带着一丝不易察觉的嘲讽" → 删状语留主句或换动作。
- 无情绪声线："声音不大，却带着……"／"语气毫无波澜""平静无波""听不出情绪" → 直接写台词内容/声音特征/动作。
- 修饰词清扫：多余的形容词/定语/量词/指示代词删掉，删后不影响阅读才删。"白色的药片"→"药片"；"飞驰的汽车"→"车"；"手里那截链子"→"链子"。一次最多一个形容词，不连用不堆砌。

## G-C 情绪表达：外化与直说都行，禁抽象情绪壳【A｜三方协调口径】
三家在此曾互相矛盾，本 skill 统一如下：

| 写法 | 判 | 依据 |
|---|---|---|
| "她怕了，怕到不敢看他"（直接点名） | ✅ 允许 | SE 数据：人类会直说情绪（29% vs AI 8%） |
| "他手在抖""她一把掀了桌子"（具体外化） | ✅ 允许 | OS C 门禁 |
| "他感到一丝失落""心中涌起一股暖流""心头一震"（抽象情绪壳） | ❌ A 级 | OS 禁词 + LF 实测。读者看不到具体画面 |
| 生理渲染连番（心跳漏一拍/喉咙发紧/指尖发凉×N） | ⚠️ B 级提醒 | SE：人类只留峰值，密度高是病（数值待复算） |

判据：这句情绪读者能不能看见具体画面或对象？"怕了"能；"一丝难以言说的惆怅"不能。外化和直说**混着用**，别只留一种。
模板动作套话（同属此类，A 级，OS 词表）：深吸一口气→删或改当下动作；"眼中闪过一丝…/嘴角勾起一抹…"→"他垂下眼/他嘴角一扯"；"缓缓开口"→"说"或动作引出。

## G-D 解释腔/上帝视角【A｜OS G 门禁 + HW】
叙述者跳出角色当下去解释、剧透、总结、定性，读者闻到"作者在场"。
- 解释因果："之所以…是因为""原来…""这意味着" → 删，因果让读者从动作对话自己拼。
- 上帝剧透："她不知道的是""殊不知""多年以后""仿佛预示着" → 删（章末预告尤其毒）。
- 替读者定性："演得真好""他就是这样薄情" → 删，证据留给读者判断。
- 段首零主语评论（LF）：非首段以"听起来/值得注意的是/关键在于/不难看出…"开头且无"这/那/其/此"回指 → 补个"这"，或点明对象。（首段、有回指、对话内不改。）
- "他/她知道…""他意识到事情不对"（OS 告知类）→ 行为展示。

## G-E 比喻审【B 级，慎动｜LF+OS】
比喻本身不是 AI 味（人类用得多），只处理三况：
- **理想化职业喻体**：把工具/系统比作"一位智慧的导师/永不疲倦的初级审查员/贴身的数字秘书"，喻体带褒义修饰或后接"不仅…更…" → 改成它实际做了什么。
- **抽象命运喻**："命运的齿轮/早已布好的棋局/露出獠牙"（OS 抽象类）→ 落回文件/动作/物理后果。
- **成片堆叠、替读者总结意义**的比喻 → 保留最能传信息/情绪的一两个，其余改白描；**别用新比喻替换旧比喻**。
生活化/角色化比喻（"像一头被抛弃的野狗"）保留。

## G-F 翻译腔五结构【A 级触发，LF 只认这五种】
① 过长前置定语（名词前修饰超约十五字，或两个以上"的"连用）→ 拆成两个分句，信息不动。
② "当……时"前置时间从句 → 删"当""时"，从句直接作前分句。（"的时候"口语是 C 级保留。）
③ 前置话题壳："对于……来说/对……而言/就……而言/关于……" → 对象放主语位，删壳。（确需限定范围、删后成全局断言时 C 级。）
④ 句首连接词当路标："然而/因此/此外/与此同时"句首尤其相邻段连续这样开头 → 移主语后或换"不过/其实/也"。（论证确需显式转折时 C 级。）
⑤ "这意味着/这表明/这说明/换句话说"开头且与前句同义 → 并入前句或只留结论。（后句给新结论时 C 级。）
同一句命中多条，按顺序靠前的条改，改完不叠加。

## G-H 相邻句同构 / 顿号三连 / 句长模板【A｜LF 实测稳定】
- **相邻句同骨架连复现**：连着两句以上逗号数相同、成分顺序相同、长度接近（"主语+动宾，+补充"连发）→ 打散一句的句法，合并/拆分/换语序。（只改句内，不动段落顺序，不删信息。）
- **顿号罗列过密**：一个分句内两个以上顿号串起三项以上并列（AI 3.21 vs 人类 1.78/千字）→ 能概括就概括；必须保留三项时改变其中一项句法。**不改**：材料必须完整列出的（法规/配置项/财务科目）、Markdown 列表内。
- **句内同构排比是 C 级**（"更高效、更专注、更有创造力"人类也用），别删——抓的是跨句复现与抬价排比，不是句内三连。
- 一个分句内三个以上平级案例凑数（LF：AI 案例句密度为人类 3-4 倍）→ 合并同类或压次要为半句，最有代表性的留主句。叙事推进不算，别动。

## G-I 小标题编号【A｜LF】
小标题以"一、二、三"或"第一、第二"通篇编号（三个以上）→ 删编号留原有文字，不改措辞顺序层级。**不改**：正文"首先…其次…最后"、句内"第一，"、Markdown 有序列表、原文按步骤组织且编号承担指代（"见第三条"）。只一两个编号不构成通篇则不动。

## 收尾检查（改完每句过一遍）

1. 每处改动能不能指出对应门禁？指不出的撤销恢复原文。
2. 是否把改动限制在解决命中所需的最小范围？没顺带润色？
3. 原话/引文、对话里的固定腔（除非是模板腔本身）有没有被统一掉？——**原话是承重的，不规整化**。
4. 有没有把被动句、名词化、长句本身当翻译腔改掉？（C 级，必须保留。）
5. 有没有为了"像人"补虚词、加口语、硬拆段？（LF：这两项不在改写范围内。）

## 权责边界
- 本层只管句子。段落/结尾归 passes；禁词黑话归 hard-bans；结构归 architecture。一层发现邻层问题，标注并转交，别越层动刀。
